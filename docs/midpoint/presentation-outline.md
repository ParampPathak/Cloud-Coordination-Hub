# Five-minute presentation: six slides

| Slide                     | Time      | Content                                                                                                                                                                                                                                       |
| ------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Cloud Coordination Hub | 0:00–0:30 | Team/project title. One authenticated workspace for events, decisions and office hours. Explain midpoint scope.                                                                                                                               |
| 2. Problem and solution   | 0:30–1:10 | Fragmented forms, spreadsheets and scheduling tools create manual administrative work. Centralize capacity, voting and reservations.                                                                                                          |
| 3. AWS architecture       | 1:10–2:10 | Mermaid diagram: ALB → private EC2 → regional DynamoDB via gateway endpoint. Two AZs, Auto Scaling, existing IAM profile, CloudWatch/CloudTrail distinction. Explain Academy limits, no Cognito, no automatic deployment.                     |
| 4. Working implementation | 2:10–3:10 | React/Express/TypeScript; local persistent SQLite; DynamoDB adapter; atomic waitlist promotion; password auth and role/owner checks; tests/build/CI. Label cloud resources as prepared.                                                       |
| 5. Results and challenges | 3:10–4:10 | Real local screenshots and concurrency evidence. Show one seat/two people promotion. Challenges: read-only IAM, private image distribution, HTTPS prerequisites, unavailable Docker locally, aggregate scale bounds.                          |
| 6. Remaining work         | 4:10–5:00 | Later authorized DynamoDB Local/container verification where needed, approved instance profile/certificate/AMI, reviewed change set, actual cloud evidence, two-instance resilience/performance tests, CSV import and poll-to-event workflow. |

Use screenshots from `docs/screenshots/` with “Local prototype · SQLite · sample test records” captions. Do not use screenshots that imply an AWS deployment occurred. Put the working demonstration after these five minutes, using [demo-script.md](demo-script.md). Speaker should distinguish implemented application security from prepared cloud IAM/network policies.
