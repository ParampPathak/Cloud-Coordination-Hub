# Midpoint rubric: 50 points

| Category                  | Points | Review evidence                                                                                                                                          | Remaining evidence                                                                                        |
| ------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Technical progress        | 15     | Working events/waitlists, polls, appointments, authentication, persistent local storage, concurrency/security tests, DynamoDB adapter and CloudFormation | Actual DynamoDB Local/container run where unavailable; actual AWS service integration after authorization |
| Architecture and clarity  | 10     | Architecture diagrams, subnet/request/data flow, existing-profile strategy, Academy constraints, database rationale                                      | Account-specific profile/certificate/AMI validation                                                       |
| Documentation             | 10     | README, API/data/security docs, deployment steps, progress, verification, roadmap                                                                        | Add real cloud evidence when available                                                                    |
| Demo quality              | 10     | Eight-minute reproducible script, actual local screenshots, independent user sessions and promotion                                                      | Rehearse timing on presentation machine                                                                   |
| Reflection and next steps | 5      | Risks/mitigations, limits, lessons, milestones                                                                                                           | Measured cloud availability/performance results                                                           |

- [ ] Run the checks on the presentation machine and preserve actual output.
- [ ] Rehearse the five-minute slides and five-to-ten-minute live demo.
- [ ] Keep local/cloud labels visible and accurate.
- [ ] Review the repository diff as a team before any approved GitHub push.
- [ ] Use no private student information, credentials, or session tokens in evidence.

These are evidence mappings, not a promise of awarded points. No GitHub push or AWS deployment has been performed by this implementation task.
